# I18n 包使用规则

## 导入方式

```typescript
import { createI18n } from '@muxiao-fek-base/i18n'

const i18n = createI18n({
  baseLocale: 'zh-CN',
  localeOverrides: {
    'zh-CN': {
      custom_key: '自定义文案',
    },
  },
})
```

## 使用方式

```typescript
// 获取翻译
const message = i18n.t('common.submit')

// 插值替换
const message = i18n.t('user.greeting', { name: 'John' })

// 切换语言
i18n.setLocale('en-US')

// 获取当前语言
const locale = i18n.getLocale()
```

## 规则

- key 使用下划线命名：`common.submit`
- 公共文案由 i18n 包维护
- 业务文案由各自项目维护
