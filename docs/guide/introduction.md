# 介绍

前端知识库 Monorepo 是一个基于 pnpm workspace 的前端项目模板。

## 技术栈

- **包管理器**: pnpm >= 10.28.0
- **构建工具**: Vite
- **主语言**: TypeScript
- **任务编排**: Turborepo

## 目录结构

```
muxiao-fek-base/
├── packages/       # 公共能力包
├── apps/           # 业务项目
├── docs/           # 文档站
└── scripts/        # 工具脚本
```
